Features

Six Specialized AI Agents

📈

Technical Analysis Agent

Computes SMA (20/50/200), EMA (12/26), MACD, RSI-14 Wilder, Bollinger Bands, and ATR using Google ADK. Delivers momentum signals with institutional precision.

News & Sentiment Agent

Retrieves financial news for Indian equities, performs deterministic sentiment classification (positive/neutral/negative), and identifies key corporate events with source citations.

🛡️

Risk Assessment Agent

Calculates composite risk scores (0–100), applies volatility and drawdown gates, and delivers investment recommendations: BUY / HOLD / SELL / CAUTION.

Gemini LLM-as-a-Judge

Post-analysis evaluation using Google Gemini. Scores analysis quality across multiple dimensions and identifies critical findings and limitations.

Blackboard Multi-Agent Architecture

About This Project

StockShield is an Agentic AI-based stock analysis and risk assessment system designed to help users make informed investment decisions in the Indian stock market. It uses multiple specialised agents to analyse stock prices, calculate technical indicators, retrieve financial data, and evaluate investment risks.


These agents work together through a central orchestrator and share their findings using a Blackboard architecture. Finally, the system combines all results into a structured report with stock insights, risk scores, and explanations.
